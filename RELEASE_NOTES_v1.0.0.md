# Battle Factory Remix v1.0.0

The first public release of **Battle Factory Remix**, a unified Battle Factory mod for Pokémon Red and Pokémon Crystal on Pokémon Recomp.

## What's included

**Pokémon Red** gets the completed standalone Saffron City Battle Factory: nine rental classes, seven-battle runs, rental swapping, Factory Heads, persistent BP progression, a BP Exchange, and rotating Pokémon stock.

**Pokémon Crystal** gets the full Battle Factory Remix experience: nine escalating classes, class-balanced rental pools, run-randomized typings and matching palettes, type-aware smart movesets, rental swapping, Factory Heads, persistent BP/shop progression, and daily Pokémon offers.

This release also fixes the normal Crystal Battle Tower so opponent Pokémon correctly match the level selected for the room.

## PokeSurvive

Battle Factory Remix can be used by itself. If using it together with PokeSurvive, use **PokeSurvive v1.1.1 or newer** so temporary Factory rentals are handled correctly.

## Installation

Extract `BattleFactoryRemix-v1.0.0.zip` and place the `battle_factory_recomp` folder in your Pokémon Recomp `mods` directory, then enable **Battle Factory Remix** in the launcher for Red or Crystal.

## Compatibility

- Pokémon Red
- Pokémon Crystal
- Pokémon Recomp `>=0.2.24 <1.0.0`

The internal mod ID remains `battle_factory_recomp` to preserve existing Red Factory save data.
